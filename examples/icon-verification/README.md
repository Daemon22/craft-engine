# Artifact icon verification samples

These files exist to preview the three supplied icon states. The `.nano` and `.craft` files are generated by Craft Engine's real CLI; the `.encdemo` file is a separate test envelope because this release has no encryption-only production archive format.

| Sample | Icon | How it was generated | Production format? |
| --- | --- | --- | --- |
| `compressed-only.nano` | `/craft-icons/compressed-only.webp` | `craft nano` (compression only) | Yes |
| `encryption-only.encdemo` | `/craft-icons/encrypted-only.webp` | Engine AES-256-GCM/PBKDF2 codec, with compression disabled | **No** — icon demo only; `uncraft` cannot read it |
| `compressed-and-encrypted.craft` | `/craft-icons/compressed-encrypted.webp` | `craft craft` (production compression + encryption) | Yes |

The `.craft` and `.encdemo` files use the public demo-only passphrase `CraftEngine-Icon-Demo-Only-NotForUse`. It is deliberately embedded in this README and the generator. These samples contain no private data; do not use the passphrase or artifacts for real protection.

To regenerate after installing dependencies and building the library:

```bash
npm run build:lib
node examples/icon-verification/generate-examples.cjs
```

The generator verifies a successful AES-GCM decrypt round trip for the `.encdemo` data and uses `getCraftArtifactIconForFile()` to print the icon selected for each filename. The sample source is `sample.txt`.
